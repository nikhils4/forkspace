Direct

Many agents. One map.

Every prompt becomes a step on a canvas. Go back to any step and try another idea. It gets its own copy of the code, so ideas never collide.

  • Branches with real code. A git worktree per branch and a checkpoint after every step.
  • Notes on the canvas. Keep your thinking next to the work.

Review

See the code change as it happens.

Code view shows each branch's files with an inline diff of everything the agents changed. Turn on Follow agent and every file opens the moment it is edited.

  • A timeline of steps and the files each one touched.
  • ⌘K to anything. Boards, branches, files, actions.
  • Approve right there. Permission requests show up next to the code.

! Watch out

Number('') quietly returns 0

An empty argument would pass as a real value. The agent checks raw.trim() === '' first, then uses Number.isFinite, which rejects NaN and Infinity.

✳ Concept

Fail loudly instead of silent Infinity

In JavaScript 1 / 0 returns Infinity, so bad results spread with no error. Throwing at the point of the mistake makes bugs easy to find.

What does 5 / 0 return? Throws a RangeError Returns Infinity ✓
▦ Pattern

Use never for always-exit helpers

Typing fail(): never tells TypeScript the function never returns, so after a check the value is known to be a number.

Install

Running in a minute.

  • Node 20+ and git on macOS, Linux or Windows
  • An ANTHROPIC_API_KEY
  • Open localhost:4747 and install it as an app
$ git clone https://github.com/nikhils4/forkspace
$ cd forkspace && npm install
$ npm start
  Forkspace → http://localhost:4747

Stop typing. Start directing.
