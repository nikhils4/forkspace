! Watch out

Number('') quietly returns 0

An empty input sneaks through as zero. So the agent checks first.

✳ Concept

Fail loudly instead of silent Infinity

1 / 0 gives Infinity, not an error. So the agent throws one.

Try it What does 5 / 0 return?
Right. It never throws. That's why the check matters.
▦ Pattern

Use never for always-exit helpers

fail(): never tells TypeScript this call never comes back.

Number('') coerces to 0. Guard with trim(), then isFinite().
