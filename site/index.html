Why Forkspace

Built for how coding with agents really goes

You try something, it half works, you want to go back two steps and try again. Tabs can't do that. A canvas can.

Branch from any step

Go back to any earlier step and try a different idea. Each branch gets its own git worktree, so branches never step on each other.

Every agent, one view

One board per project. See what is running, what is done, and what needs you, across all of them at once.

Notes anywhere

Drop sticky notes next to the work and link them to any step. Your thinking stays where the decisions happened.

How it works

Every reply is a step you can return to

  1. 1
    Point a board at a folder

    Any project on your Mac. Forkspace runs the same Claude Code you already use.

  2. 2
    Describe a task

    The agent works on its own card. Tools, edits and cost stream in live.

  3. 3
    Reply, or branch from any step

    Continue the latest step, or pick an earlier one to try another approach. A checkpoint after every step means nothing gets lost.

On your phone

Step away. Stay in the loop.

Install Forkspace on your phone. Get a notification when an agent needs you, tap Allow, keep walking. Agents keep running on your Mac.

  • Private. Reach your Mac through Tailscale. Nothing is open to the internet.
  • Paired. Every device signs in with a one-time 6-digit code.
  • Made for touch. Read any branch as a chat and switch branches with a tap.
Install

Running in a minute

  • macOS, Linux or Windows with Node 20+ and git
  • Claude Code signed in, or an ANTHROPIC_API_KEY
  • Then open localhost:4747 and install it as an app
$ git clone https://github.com/nikhils4/forkspace
$ cd forkspace && npm install
$ npm start
  Forkspace → http://localhost:4747

Stop juggling tabs.

Free and open source. Your code never leaves your machine.
