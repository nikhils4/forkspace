While an agent wrote a small calculator, Forkspace explained the ideas behind its code. These are the real notes.

The function calls itself on a simpler version of the same problem. Here a negative exponent becomes a positive one, and the positive case does the real work.

if (exp < 0) return 1 / power(base, -exp);
let result = 1;
for (let i = 0; i < exp; i++) result *= base;
return result;

Save answers you have already worked out. When the same inputs come back, return the saved answer and skip the work. The trade off: it never forgets, so memory grows.

Start at 1 and multiply by the base once per step. A negative exponent means divide instead, so the result is flipped: 1 divided by it.

Questions

Asked often.

What is Forkspace?

A free, open source editor for Claude Code agents. Every prompt becomes a step on a canvas. Run many agents side by side, branch from any step, and review each change as a live diff.

How is it different from the Claude Code extension or CLI?

Same agent underneath, built on the Claude Agent SDK. Forkspace adds the map: many agents at once, branches you can see, a code view per branch, approvals from your phone, and concepts explained as agents work. Your existing Claude Code sessions come in with one click.

Can I branch a Claude Code conversation?

Yes, from any step. The agent remembers everything up to that step and nothing after. In a git repo the code branches too: each branch works in its own git worktree, so branches never overwrite each other.

Can I run several Claude Code agents at the same time?

Yes. Each thread or branch is its own agent. Anything waiting for your approval glows on the canvas and shows up under Agents.

Can I use it from my phone?

Yes. Agents run on your computer and your phone is the remote. Pair over Tailscale with a 6 digit code, get a ping when an agent needs you, and tap Allow or Deny.

How do updates work?

Settings, then Update. One click pulls the new version, rebuilds and restarts it, with release notes in plain words. It ships often.

What do I need, and what does it cost?

Node 20 or newer, git, and an Anthropic API key. Forkspace itself is free under the MIT license. It runs on your machine and your code stays there.

Can I sign in with my Claude subscription?

Forkspace runs on an Anthropic API key, not your Claude.ai plan. Anthropic asks apps built on Claude Code to work that way, and it keeps your usage and costs clear.

Will agents replace me?

Not while you're the one with taste. Forkspace keeps you directing, reviewing and learning. The agents do the typing.
