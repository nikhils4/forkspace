# Security

Forkspace runs agents with your user's permissions, so security reports matter.

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/nikhils4/forkspace/security/advisories/new), not in public issues. Include steps to reproduce and the version (Settings → Forkspace).

You'll get a reply within a few days. Fixes ship as a new release, and the advisory credits you unless you'd rather not.

How Forkspace protects you today is described in the [README](README.md#security).
